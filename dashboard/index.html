Native CI onboarding

Prepare a push-triggered self-hosted workflow and open a provider review request. Routes the proposed job to your own worker.

Important: onboarding adds a smoke workflow; it does not silently migrate existing jobs. Existing hosted workflows can still consume paid minutes until reviewed and changed. Never run untrusted PR code on a persistent worker.

Pipeline cockpit

Inspect recent runs and explicitly retry or cancel. All operations happen on the provider.

My PC · secure host agent

Inspect your Garuda host and manage explicitly approved desktop apps or user services. Never grants CI jobs administrator access.

Checking local host agent…

The host agent must first be installed and started on the PC. Only allowlisted packages/services can be changed. Mobile management additionally needs a specific approved Tailscale identity. Root-level pacman installation and arbitrary commands are deliberately not available.

Diagnostics and activity
